# SpringBoot3 管理系统脚手架

技术选型：

- SpringBoot3
- Vue3

## 数据库设计

| 实体         | 表名                | 说明            |
| ------------ | ------------------- | --------------- |
| 用户         | sys_user            | 默认管理员admin |
| 角色         | sys_role            |                 |
| 权限         | sys_permission      |                 |
| 用户角色关联 | sys_user_role       |                 |
| 角色权限关联 | sys_role_permission |                 |

## 功能模块设计

### 用户管理

- 查询列表
- 查询详情
- 新增
- 删除
- 更新
- 用户关联角色

默认用户：admin

### 角色管理

- 查询列表
- 查询详情
- 新增
- 删除
- 更新
- 角色关联权限

默认角色：

- 管理员
- 普通用户

### 权限管理

- 系统管理
  - 用户管理
  - 角色管理
  - 权限管理
- 其他
